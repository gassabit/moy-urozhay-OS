# Мой урожай OS · сезон 2027
Локальный дневник одной теплицы. Запустите из каталога приложения `python -m http.server 8080 --bind 127.0.0.1` и откройте http://localhost:8080. Для телефона разместите файлы на статическом HTTPS-хостинге. После первой загрузки и установки service worker приложение доступно офлайн. Установка через меню поддерживающего браузера.

Измените паспорт, назначьте культуры трём равным грядкам, задайте дату высадки и распечатайте план. Сроки привязаны к указанной дате. Регион служит подписью. Оценка количества растений условна. Задачи отмечаются вручную. Каталог содержит два доступных материала. Оплаты и серверной части нет.

Проверка модели: `node --test test.mjs`. Данные хранятся в localStorage конкретного браузера, очистка данных сайта удалит записи. При недоступности хранилища приложение показывает предупреждение. CSP ограничивает ресурсы текущим источником. Пользовательский текст выводится через DOM. Сборки и внешних зависимостей нет. При обновлении статических файлов повышайте версию кеша в sw.js. Для публикации задайте HTTP-заголовки X-Content-Type-Options: nosniff и Content-Security-Policy: frame-ancestors 'none'.

В разделе «Резервная копия» можно скачать дневник как JSON и восстановить его в другом браузере. Восстановление заменяет текущий дневник после подтверждения.
