# Мой урожай OS · сезон 2027

Мобильный дневник одной теплицы. [Открыть тестовую версию](https://gassabit.github.io/moy-urozhay-OS/).

## С чего начать

1. В паспорте укажите регион, размеры теплицы и плановую дату высадки.
2. На карте назначьте культуры трём продольным грядкам. Приложение покажет примерное количество растений по каждой грядке и общий итог.
3. В плане сезона добавьте одну работу или весь план в задачи. В задачах можно менять название и срок, отмечать выполнение и фильтровать список по статусу.
4. Скачайте файл календаря (.ics), чтобы импортировать даты в календарь, или распечатайте план. В каталоге отдельно печатаются карта грядок и чек-лист перед высадкой.
5. Скачайте резервную копию (.json). Чтобы перенести дневник, откройте приложение на другом устройстве и выберите файл в разделе «Резервная копия». Восстановление заменяет текущий дневник после подтверждения.

## Установка и данные

Откройте приложение с интернетом. В Chrome на Android используйте меню установки или добавления на главный экран. На iPhone откройте сайт в Safari и выберите «Поделиться» → «На экран Домой». После первой загрузки приложение можно открыть без сети. Если после обновления видна старая версия, закройте все окна приложения и снова откройте его с интернетом.

Дневник хранится в браузере на этом устройстве. Синхронизации и оплаты нет. Очистка данных сайта удалит дневник, поэтому для переноса или восстановления понадобится сохранённая копия.

## Как рассчитывается план

Приложение предполагает три равные грядки и отводит 70% площади под посадки. Для томатов и огурцов используется условная плотность 2 растения на м², для перцев — 3. Результат округляется вниз по каждой грядке. Расстояния уточняйте по сорту. Даты работ отсчитываются от введённой даты высадки. Регион сохраняется как подпись.

## Локальный запуск

В каталоге приложения выполните `python -m http.server 8080 --bind 127.0.0.1` и откройте http://localhost:8080. Для тестов запустите `node --test test.mjs`. Проект работает без сборки и внешних зависимостей. Для хостинга требуется HTTPS для работы service worker.

При обновлении файлов повышайте версию кеша в sw.js. При настройке своего хостинга используйте заголовки X-Content-Type-Options: nosniff и Content-Security-Policy: frame-ancestors 'none'.
